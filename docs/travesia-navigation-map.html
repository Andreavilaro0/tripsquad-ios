Flujos Lógicos del Sistema
🔔 Push Notifications sin implementar
El NotificationRouter existe en el repo pero no hay routing real. Una notificación de "nuevo gasto" debería navegar directamente a ExpensesHubView del trip correcto. Falta: URL scheme, AppRouter.handleNotification(), deep link por tipo (chat, gasto, voto, actividad).
🔗 Deep Linking sin implementar
No hay URL scheme configurado (travesia://). JoinTripView funciona por código manual, no por link universal. Falta: entitlement Associated Domains, onOpenURL handler en App, routing desde link → vista correcta.
📡 Offline Mode parcial
NetworkMonitor (@Observable) está implementado y en el entorno DI. Pero los estados de UI offline (banners, deshabilitación de acciones, caché local) no están diseñados ni implementados en las vistas.
🎉 First Launch CTA sin implementar
Tras completar onboarding, el usuario llega a HomeView vacío. No hay CTA "Crea tu primer viaje" ni guía contextual. El estado HubDiscoveryView muestra destinos pero no orienta al usuario recién llegado.
🔄 Session Expiry sin implementar
Si el token de Supabase expira mientras la app está en uso, el comportamiento es incierto. Falta: interceptor de error 401, refresh automático de token, redirect a AuthGate con mensaje de sesión expirada.
💳 Premium Upgrade parcial — bloqueado
BrujulaPaywallView existe con UI completa. SubscriptionUseCase y SubscriptionRepository implementados. Bloqueado por falta de product IDs en App Store Connect. StoreKit code existe, no puede activarse.
📲 Real-time Sync parcial
Chat ✅, Expenses ✅, Voting ✅ tienen real-time via Supabase Realtime. Itinerary, Photos, Checklist y Squad NO tienen subscripciones en tiempo real — requieren pull-to-refresh manual.
🗑 Account Deletion parcial
PrivacidadView tiene el botón "Eliminar cuenta" con danger zone. No está conectado a lógica real: falta AuthUseCase.deleteAccount(), limpieza de datos Supabase (trips, gastos, fotos), confirmación y logout final.
🔄 Background Refresh sin implementar
Cuando la app vuelve a foreground, no hay refresh automático de datos. Cada ViewModel hace fetch en onAppear pero no hay BGTaskScheduler para mantener datos frescos. Crítico para viajes en curso (itinerario, gastos, mensajes).

APIs Externas Integradas
🧭 Anthropic Claude activo
api.anthropic.com/v1/messages
Brújula IA. Modelo claude-opus-4-5. Request: contexto del viaje + prompt de usuario. Response: JSON estructurado con sugerencias. Mock fallback si falla.
💱 Frankfurter activo
api.frankfurter.app/latest
Tipos de cambio en tiempo real. Gratuito, sin API key. ForexService actor: cache in-memory 5 min, retry exponential 3x. Wired en AddExpenseViewModel y HubForexWidget.
🌦 Open-Meteo activo
api.open-meteo.com/v1/forecast
Pronóstico del tiempo por coordenadas GPS. Gratuito, sin API key. Usado en HubWeatherWidget y en ItineraryView (weather por día). Parámetros: lat, lon, daily, timezone.
🎫 GetYourGuide activo
widget.getyourguide.com
Experiencias y tours en HubDiscoveryView. Integrado vía WebView / iframe embed. Bug conocido: thumbnails superponen TSNavBarFloating → tap en tab bar abre GYG en lugar de cambiar tab. Fix pendiente: padding bottom.
💳 Apple StoreKit bloqueado
StoreKit 2 · App Store Connect
In-app subscriptions para Brújula Premium. BrujulaPaywallView tiene UI completa. SubscriptionUseCase y SubscriptionRepository implementados. Bloqueado: necesita product IDs de App Store Connect para activar.
🗄 Supabase activo
*.supabase.co (xcconfig)
PostgreSQL + Auth + Realtime + Storage. 25 migrations aplicadas en remote. Credenciales en .xcconfig, nunca en código. Anon key en allowlist de gitleaks. RLS en todas las tablas. my_trip_ids() SECURITY DEFINER previene recursión.
